# 当前实现与验收审查

## 结论

截至 **2026-07-26**，小白一号已从本地 MVP 升级为可运行的真实小说生成服务。本轮按第一性原理和 Murphy 定律重新审查了“输入 → 模型配置 → 后台运行 → 章节落盘 → API 扫描 → UI 实时预览 → TXT 导出”的完整链路，并完成生产真实模型验收。

## 本轮关键故障与根因

历史故障表现为“显示生成三章，但实时预览只有两行短内容”。根因不是 React 裁剪正文，而是生产环境误用了 `mock`：旧 mock 固定生成三章，每章只有极短示例；UI 又没有明确区分模拟内容，并且轮询时没有持续重新拉取当前章节详情。

修复原则：

1. 生产显式使用 `ainovel`，模拟模式在 API 和 UI 中都必须可识别。
2. 章节完成数只相信磁盘上的实际章节文件，不相信进程自报进度。
3. UI 的“实时”必须刷新章节详情，而不只是刷新章节列表。
4. 达到目标章节立即停止；停止失败时不能误报完成。
5. 任何凭证、Docker、容器、目录或导出异常都要 fail closed。

## 已落地保护

### 生成与状态机

- fresh 使用 `--headless --prompt <prompt>`；resume 只使用 `--headless`，避免继续创作时重复注入首轮提示。
- mock 遵守目标章节数，并明确写入“模拟验收内容”提示。
- 真实完成数由 `.md`、`.markdown`、`.txt` 章节文件扫描得出。
- 监控启动后立即同步，之后每秒检查一次；达到目标后 stop，失败再 kill，两者都失败则保留运行态并重试。
- API 重启恢复活跃任务监控；Docker 不可用或容器丢失时标记失败，不伪造成功。
- 完成、失败或暂停后的生成容器会尝试删除，避免长期积累。
- 生成子容器限制内存、CPU 和 PID；低内存生产机全站并发固定为 1。
- Docker 慢操作不持有 SQLite 全局事务锁。

### 数据、章节与导出

- 章节读取兼容 BOM、CRLF、大小写后缀与原子替换窗口。
- 没有明确章节标题时回退为文件名推导标题，不再把正文第一句误判为标题。
- API 返回字符数、段落数和 ISO 8601 更新时间。
- 单章和全书 TXT 均移除 Markdown；空作品全书导出返回 404。
- 历史 mock 作品保留，不篡改用户已有数据；新任务使用真实引擎。

### 凭证与部署

- 凭证必须先保存，再用完全一致的参数测试成功，才允许启动真实生成。
- 配置目录权限 `0700`，`config.json` 权限 `0600`。
- `ainovel` 模式必须配置宿主机绝对路径 `XIAOBAI_HOST_DATA_DIR`；缺失或相对路径时拒绝启动。
- 升级 rsync 排除 `.git`、生产 `.env`、生产数据、虚拟环境、依赖目录和构建产物。
- 本地验证脚本使用独立项目名、端口、网络和数据目录，不会覆盖生产配置或数据库。

### UI

- 暖白纸张、暖灰侧栏、陶土主色，减少装饰噪声并提高长文可读性。
- 工作台、模型连接、邀请与系统、账号安全均统一视觉和状态表达。
- 运行中每 2.5 秒重新请求作品与当前章节详情。
- 默认跟随最新章节；手动选择旧章节后保持用户选择。
- 显示字符数、段落数、更新时间，提供复制、单章下载和全书导出。
- 桌面侧栏与移动端底部导航，无横向溢出；图标按钮有可访问名称。

## 验收证据

- API 单元/集成测试：14 项通过。
- Web 生产构建通过。
- 生产健康接口同时经本机端口和公网域名返回 `engine_mode=ainovel`。
- 真实模型生成目标 1 章，最终只落盘 1 个章节文件。
- 验收章节：1,731 字符、42 段、4,891 bytes、83 行；UI 显示完整连续正文而不是两行短文。
- 单章和全书 TXT 均成功导出且不含 Markdown 标题符号。
- 桌面 1440×1000 与移动 390×844 浏览器验收：横向溢出 0、无空白可访问按钮、控制台/运行时/失败网络请求 0。
- 生产 SQLite `integrity_check=ok`；历史模拟作品仍存在。
- 其他现网容器未被停止或重建。

## 仍需长期治理的风险

1. API 仍直接挂载 Docker socket，权限过高；建议迁移到 socket proxy 或专用 runner。
2. 模型密钥曾进入 Git 历史；当前工作树已移除，但必须轮换密钥，并安排历史清理。
3. CLI 没有已验证的原生“目标章节数”参数，当前依赖文件扫描与 1 秒监控停止；仍存在极小的下一章启动窗口。
4. 生产机约 1.6 GiB 内存且无 swap；必须维持全站真实生成并发为 1。
